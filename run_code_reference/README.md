# run_code_reference/

Verbatim copies of the original run scripts that produced the manuscript
results (see docs/DIFFERENCES_FROM_RUN_CODE.md for the mapping).

- These files retain the original hard-coded server paths and in-house data
  loader imports; they are provided as **provenance**, not as turn-key
  executables.
- To actually run the core analyses on your own data, use the config-driven
  equivalents in `scripts/`.
- Data and model checkpoints are NOT included anywhere in this repository.
